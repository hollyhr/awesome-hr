# Awesome HR

A curated collection of useful, maintained resources for people operations,
employment practice and HR technology—with an emphasis on UK teams and open
developer standards.

This is a practical starting point, not legal advice or a directory of every HR
vendor. Links are selected for authority, usefulness and maintenance.

## UK employment essentials

- [Acas](https://www.acas.org.uk/) — free, impartial workplace-rights and
  employment-practice guidance for employers and workers.
- [Employ people — GOV.UK](https://www.gov.uk/browse/business/employ-people) —
  the government index for hiring, contracts, payroll, leave and ending
  employment.
- [Employment status and rights checklist](https://www.gov.uk/government/publications/employment-status-and-employment-rights/employment-status-and-rights-checklist-for-employers-and-other-engagers)
  — a current employer checklist for distinguishing employees, workers and
  self-employed people.
- [Holiday entitlement](https://www.gov.uk/holiday-entitlement-rights) —
  statutory leave rules and links to the official calculator.
- [Statutory Sick Pay employer guide](https://www.gov.uk/employers-sick-pay) —
  current eligibility, rates and employer responsibilities.
- [Check a job applicant's right to work](https://www.gov.uk/check-job-applicant-right-to-work)
  — the official online and document-check routes.
- [The Pensions Regulator: automatic enrolment](https://www.thepensionsregulator.gov.uk/en/employers)
  — employer duties and guidance.

## Privacy, safety and accessibility

- [ICO employment information](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/employment/)
  — UK GDPR guidance for employers handling worker information.
- [ICO small-business data protection hub](https://ico.org.uk/for-organisations/advice-for-small-organisations/)
  — plain-language privacy guidance and tools.
- [HSE: managing health and safety](https://www.hse.gov.uk/simple-health-safety/)
  — practical health-and-safety guidance for smaller organisations.
- [W3C Web Content Accessibility Guidelines](https://www.w3.org/WAI/standards-guidelines/wcag/)
  — the core accessibility standard for employee-facing software.
- [OWASP API Security Top 10](https://owasp.org/API-Security/) — common API
  risks relevant to systems containing employee data.

## Open-source HR software

- [Frappe HR](https://github.com/frappe/hrms) — HR and payroll software built
  on the Frappe framework; GPL-3.0.
- [OrangeHRM](https://github.com/orangehrm/orangehrm) — community HR management
  system; GPL-3.0.
- [Horilla HR](https://github.com/horilla/horilla-hr) — Django-based HR
  software; LGPL-2.1.
- [Odoo](https://github.com/odoo/odoo) — broad business application suite with
  HR modules; check the licence of the edition and add-ons you use.

Inclusion here is not an endorsement. Review security posture, release activity,
licensing, regional payroll assumptions and operational ownership before
adopting any HR system.

## Standards for HR integrations

- [OpenAPI Specification](https://spec.openapis.org/oas/latest.html) —
  language-neutral HTTP API contracts.
- [SCIM core schema — RFC 7643](https://datatracker.ietf.org/doc/html/rfc7643)
  and [SCIM protocol — RFC 7644](https://datatracker.ietf.org/doc/html/rfc7644)
  — interoperable identity provisioning.
- [CloudEvents](https://cloudevents.io/) — a common event-envelope
  specification.
- [OpenID Connect](https://openid.net/developers/how-connect-works/) — identity
  on top of OAuth 2.0.
- [WebAuthn](https://www.w3.org/TR/webauthn-3/) — public-key credentials and
  passkeys.
- [Model Context Protocol](https://modelcontextprotocol.io/specification/) —
  an open protocol for exposing tools and context to compatible AI clients.

## Developer resources

- [HollyHR developer docs](https://developers.hollyhr.com) — REST API, OpenAPI,
  TypeScript SDK, webhooks and hosted MCP from this list's maintainers.
- [HollyHR API examples](https://github.com/hollyhr/hollyhr-api-examples) —
  runnable read, pagination, safe-write, webhook and MCP examples.
- [JSON Schema](https://json-schema.org/) — portable validation contracts used
  by OpenAPI and many event systems.
- [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) — concise
  implementation guidance for authentication, authorisation, secrets and other
  security boundaries.

## Contributing

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing a link.
Additions should be:

- directly useful to HR operators or people-technology builders;
- maintained and linked to their authoritative source;
- clear about geography, licence and commercial status where relevant;
- free of referral codes, affiliate links and unverifiable superlatives.

Commercial tools are considered only when their documentation or open
specification is independently useful. This list will not become a pay-to-play
vendor directory.
